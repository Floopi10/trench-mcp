# Verification ledger

## Solana migration

Earlier chain-specific observations are superseded. This repository now targets **Solana mainnet-beta** and validates public base58 token addresses, DexScreener's `solana` market surface, and the configured Solana JSON-RPC `getHealth` + `getSlot` calls.

Run `npm run check` after any change. Live RPC and provider values are intentionally not stored here because they drift by request.

## Limits

A passing local suite verifies code paths and fixtures. It does not prove provider availability, liquidity, transaction execution, token safety, or financial outcomes.
